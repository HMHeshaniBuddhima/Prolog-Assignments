1. Map Coloring Problem (`map_coloring.pl`)
   - Solves the graph/map coloring problem using Prolog constraint satisfaction.
   - Assigns colors to regions ($a, b, c, d, e$) such that no adjacent regions share the same color.

2. Monkey and Banana Problem (`monkey_banana.pl`)
   - Implements state-space search and goal-state planning in Prolog.
   - Generates a sequence of actions (`walk`, `push`, `climb`, `grasp`) to achieve the goal state.
